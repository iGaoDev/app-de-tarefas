# TaskFlow - Gestor de Tarefas

Um aplicativo de tarefas moderno, limpo e responsivo, desenvolvido como o meu primeiro projeto de desenvolvimento web. O objetivo é ajudar na organização diária com uma interface elegante e um fundo animado personalizado.

## 🚀 Funcionalidades

- **Adicionar Tarefas:** Regista facilmente as tuas missões e tarefas diárias.
- **Marcar como Concluída:** Controla o teu progresso com risco nas tarefas feitas.
- **Persistência de Dados:** As tarefas são guardadas no armazenamento local do navegador (`localStorage`), garantindo que não perdes nada ao atualizar a página.
- **Fundo Animado:** Efeito visual moderno de partículas em movimento desenvolvido com JavaScript (Canvas).
- **Design Responsivo:** Adaptado para computadores e telemóveis.

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação)
- **CSS3** (Estilização, fontes e design moderno)
- **JavaScript (Vanilla)** (Lógica, manipulação do DOM e animação)
- **GitHub Pages** (Deploy e Hospedagem)
